# myPortal 演示界面

给领导汇报用的可点击 HTML 界面原型。**双击 `index.html` 即可用浏览器打开**，
不需要服务器、不需要联网、不需要装任何东西。

---

## 怎么用

1. 双击 `index.html`（推荐 Chrome / Edge）
2. 左侧选租户 → 填账号密码 → 点「登录门户」
3. 左侧菜单可切换 **21 个界面**，全部可点

## 技术说明

- **单文件**：`index.html` 内含全部 HTML / CSS / JS，无外部依赖、无 CDN、无构建步骤
- **图表为手写 SVG**（折线 / 环形 / 条形 / 堆叠），不是图表库——所以离线可用、体积小
- **设计令牌**来自 `fortiportal/design-system/MASTER.md`：深蓝主 `#1E40AF` + 浅蓝辅
  `#3B82F6` + 琥珀强调 `#D97706`，8 级严重度各自独立的颜色 / 底色 / 边框三件套，
  浅色与深色主题各一套（同一个色值在两种底色上都过 WCAG AA 4.5:1）
- **中文字体**统一 Microsoft YaHei
- **无障碍**：跳转导航链接、连续标题层级、可见焦点环、严重度不靠颜色单独传达、
  尊重 `prefers-reduced-motion`、375px 起无横向滚动
- **语言机制**：语言优先级 = 用户选择 > 租户语言 > 门户缺省（中文）；
  切换后写入 `localStorage`，下次打开保持

### 新增：漏洞管理

按资产组织的漏洞清单，**31 条**，每条都带影响评估与修复建议。

| 演示要点 | 看什么 |
|---|---|
| 严重度 × 修复可行性矩阵 | 气泡图。**右上象限是真需要决策的部分** —— 高危且打不了补丁的漏洞 |
| 漏洞清单 | 可搜索、可按严重度与修复可行性筛选；点任意一行看详情 |
| 详情面板 | CVSS 向量 · 技术描述 · **影响评估** · 修复方案 · **无法立即修复时的替代措施** · 对应 UR 条款 |
| 三条为什么 | 「互联网侧可以直接打补丁；CBS 不行」—— 为什么 OT 的修复建议不一样 |
| 处置优先级 | 按「资产关键度 × 可达性」排序，**不按漏洞数量** |

修复可行性分四档：**可立即修复 / 需安排变更 / 仅可缓解 / 不可修复（许可阻塞）**。
最后那档（3 条 Siemens S7-1500）之所以不可修复，是因为设备不在固件维护服务范围内
—— 对应「许可证管理」里的 FMWR 组件。

### 双语

新增的 OT 与漏洞模块，以及**全部 25 个界面**，都支持中英双语：

- 切换语言即时生效，无需刷新
- **缺省中文**；用户选择写入 localStorage，下次打开保持
- 精确文案走 `L()`（数据自带 zh/en 两份），早期页面走一张集中翻译表兜底
- 未覆盖的中文会在浏览器控制台列出 —— **漏翻是可见的**，不会悄悄留在界面上

自检：`python ../tools/check_demo.py`（30 项，含内联 JS 语法、双语完整性、零外部依赖）

### 新增：UR 条款追溯（组 → 子模块 → 独立页面）

三层结构，点到最细：

```
UR 条款追溯（6 组 · 70 个子模块）
   └─ 点组卡 → 该组的子模块列表（如「网络与防护」29 个）
        └─ 点子模块 → 独立页面（urm:<id>，有独立 URL、标题、面包屑）
```

每个子模块页有：台账记录表（自己的列与数据）、CVSS 式的条款映射、
检验须提交的材料、证据条目数、同组其他子模块。

**组计数从数据算出来**，不是手写死的 —— 否则加一个模块就会出现两处数字不一致。

| 文件 | 作用 |
|---|---|
| `tools/ur_modules_data.py` | 70 个子模块的注册表（唯一事实来源） |
| `tools/ur_values_en.py` | 台账单元格值的中英对照表 |
| `tools/build_ur_modules.py` | 注入器，可重复执行（幂等） |

**构建期守卫**：台账里出现的每一个中文单元格值，必须在对照表里有英文，
缺一条直接构建失败 —— 而不是让英文界面悄悄留着中文。

### 新增：资产导入 / 导出（导入页带 AI 辅助）

资产清单页右上角两个入口：**导入 ↑** / **导出 ↓**。

**导出**：格式（CSV / JSON）、范围（全部 / 已关联 / 待关联）、字段勾选、脱敏开关，
右侧实时预览，生成**真实可下载**的文件。勾了脱敏后 IP 与序列号以掩码输出，
但页面明确写了：**掩码后的清单不能作为检验证据**，因为无法回溯到具体资产。

**导入 + AI 辅助**：拖放 CSV/TXT 或直接粘贴（支持从 Excel 复制）→ 点「AI 解析」：

- **字段映射建议** —— 每列映射到哪个目标字段，带置信度，可手工改
- **发现的问题** —— 缺必填、与已有资产重复、安全区域不在允许列表
- **导入预览** —— 逐行给出「可以导入 / 跳过 / 需人工填写」

**AI 的职责边界**（与 AI 助手页一致，页面右侧专门有一栏说明）：

| | |
|---|---|
| **AI 负责** | 识别分隔符与表头、中英文列名对到目标字段、标出没把握的地方 |
| **规则负责** | 必填校验、去重键、允许值域、租户作用域 —— 服务端判定，模型无权改 |
| **所以** | 每一处「不确定」都要人确认后才入库 —— AI 的输出是建议，不是结果 |

去重键为 `natural_id`，其次名称与序列号。**已有资产不会被覆盖**，重复行一律跳过并列出。
